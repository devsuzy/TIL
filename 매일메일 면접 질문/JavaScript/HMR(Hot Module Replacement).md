# HMR(Hot Module Replacement)

### HMR(Hot Module Replacement)이란?
- 웹 개발 중 코드를 수정하고 저장했을 때, 브라우저 전체를 새로고침(Reload)하지 않고도 변경된 모듈만 실시간으로 교체해 주는 기능
- 상태(state)나 입력값을 유지한 채 화면만 빠르게 업데이트할 수 있어 개발 생산성을 크게 높임

### HMR의 주요 장점
- **상태 유지(State Preservation):** 페이지가 새로고침되지 않으므로 입력 폼에 작성한 내용이나 클릭해서 열어둔 메뉴 상태 등이 그대로 유지
- **빠른 개발 속도:** 전체 애플리케이션을 다시 빌드하고 페이지를 새로 로드하는 시간이 절약되어, 수정 사항을 즉시 확인하여 개발에만 집중 가능
- **스타일 수정 최적화:** CSS나 UI 컴포넌트를 수정할 때 특히 유용하며, 변경된 디자인이 브라우저에 즉각 반영

### HMR의 작동 방식
- 개발자가 코드를 수정하면 빌드 도구(예: Webpack, Vite 등)가 변경 사항을 감지
- 변경된 모듈이 HMR 런타임에 전달되면, 기존 모듈을 새 모듈로 교체(Patch)하고 애플리케이션에 변경 사실을 알려 전체 새로고침 없이 화면에 업데이트되도록 처리
